# Задание на дом Intern C++ (SafeBoard\_2026p2)

## Цель

Реализовать потокобезопасный класс `FileCollector`, который собирает файлы, передаваемые по сети чанками в произвольном порядке.

## Условие

- Сетевое взаимодействие реализовывать не требуется.
- Файл передаётся чанками, содержащими данные и позицию в файле.
- Чанки могут приходить в произвольном порядке.
- Один файл может собираться несколькими потоками одновременно.
- Гарантируется, что содержимое файлов не изменяется в процессе передачи, но отдельные чанки могут пересекаться.
- Класс должен быть потокобезопасным и обеспечивать эффективное восстановление файла из полученных чанков.

## Пример пересекающихся чанков

Допустим, передаётся файл размером 10 байт, и приходят следующие чанки:

1. `OnNewChunk(field, 0, {A, B, C, D})` — первые 4 байта (`pos = 0`).
2. `OnNewChunk(field, 2, {C, D, E, F})` — пересекается с предыдущим (начиная с `pos = 2`).
3. `OnNewChunk(field, 6, {G, H, I, J})` — не пересекается с предыдущими.

В памяти файл должен собираться так:

```text
[A, B, C, D, E, F, G, H, I, J]
```

## Цель

Необходимо написать консольную программу для ОС Windows на C++, которая принимает на вход идентификатор (`pid`) или имя процесса и выводит в консоль информацию о регионах памяти указанного в аргументах процесса, которые возможно прочитать.

## Условие

В системе уже запущен целевой процесс, который не связан с создаваемой программой. Регионы памяти целевого процесса могут иметь все возможные параметры защиты. В реализуемой программе можно использовать WinAPI. Возможность чтения региона должна определяться путем сравнения с параметрами защиты регионов, которые указаны константными значениями в коде программы. Другие причины, помимо параметров защиты, которые могут не позволить прочитать регион, можно не учитывать.

## Что нужно сделать?

- По идентификатору или имени найти целевой процесс в системе.

- Вывести в консоль только те регионы целевого процесса, которые доступны для чтения. То есть только те, которые создаваемая программа может прочесть через `ReadProcessMemory` без возникновения ошибки доступа. Например, `PAGE_NOACCESS` не позволит выполнить операцию чтения и вернётся ошибка.

- Для каждого региона вывести адреса начала и конца региона, параметры защиты.

- Для корректного выполнения задания рекомендуем не полагаться исключительно на открытые источники, а провести любым способом самостоятельное исследование для определения параметров защиты регионов, которые разрешают чтение.
